## Make a new version

1. Edit `generator/cv.json` (all wording, dates and links live there).
2. Double-click `build.cmd` (or run it from a terminal).

That rebuilds `latest/` (PDF, 300 dpi PNG, self-contained HTML, Markdown). If the content changed since the
last archived version, it also saves a dated copy in `archive/YYYY-MM-DD/`, including the `cv.json` that produced it.

The first run creates a Python environment in `.venv/` and downloads Chromium (needs Python 3.10+ on PATH).
If the build fails (e.g. the CV no longer fits on one A4 page), `latest/` is left untouched and the error says why.

If the PDF is open in a viewer, the build stops and asks you to close it; nothing is half-replaced.

To also put it online, double-click `publish.cmd` instead: it builds, copies the result into `docs/` (the GitHub
Pages site) and commits and pushes this repo. Only the files whitelisted in `.gitignore` are ever committed.

Options: `build.cmd --no-archive` (don't snapshot), `build.cmd --html-only` (HTML/Markdown only, no PDF),
`build.cmd --output <folder>` (build a preview somewhere else; never archived).

## Layout

| Folder | Contents |
| --- | --- |
| `latest/` | The current CV. Generated — don't edit by hand. |
| `generator/` | `cv.json` (content), `template.html` + `cv.css` (layout), `assets/` (portrait, artwork, icons), `build.py`. |
| `docs/` | The public website (GitHub Pages). Generated by `publish.cmd`. |
| `archive/` | Every previous version by date (local only). |
| `documents/` | Application paperwork (local only). |
| `photos/` | Photos (local only). |
| `personal/` | Private documents. **Local only — never send with a CV.** |

## Notes

- Fonts: the PDF uses Liberation Serif/Sans (installed on this PC). The build warns if they're missing.
- Portrait: `generator/assets/portrait-original.png`. The blue backdrop is removed automatically
  (`remove_background` in `cv.json`); that step is tuned to this photo, so check the result if you swap it,
  or set `remove_background` to `false`.
- Long phrases kept on one line (e.g. "Daniel Litt") are listed in `typeset()` in `build.py`.
- Private sourcing notes live in `generator/review_notes.json`, which is never committed or shown on the CV.
- Only `README.md`, `build.cmd`, `publish.cmd`, `generator/`, `latest/` and `docs/` are in git. `archive/`,
  `documents/`, `photos/` and `personal/` stay on this PC only.
